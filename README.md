# Arch Hiero

A fast, native diagramming app written in Rust with [egui](https://github.com/emilk/egui) and wgpu.
It targets macOS today, with Windows and Linux planned.

```sh
cargo run -p hiero-app --release
```

Contributor and agent guidelines: [AGENTS.md](AGENTS.md).
